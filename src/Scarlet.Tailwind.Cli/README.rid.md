# Scarlet.Tailwind.Cli.*

This package is a per-platform implementation detail of
[`Scarlet.Tailwind.Cli`](https://www.nuget.org/packages/Scarlet.Tailwind.Cli/), restored automatically for
you by `dotnet tool install`/`dotnet tool restore`. It carries no library assets, so `dotnet add package` on
it installs nothing usable.

Install `Scarlet.Tailwind.Cli` instead:

```bash
dotnet tool install --global Scarlet.Tailwind.Cli
```

See [`Scarlet.Tailwind.Cli`](https://www.nuget.org/packages/Scarlet.Tailwind.Cli/) for full documentation.
